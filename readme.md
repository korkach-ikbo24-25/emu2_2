## Этап 4. Порядок загрузки зависимостей

Инструмент выводит порядок загрузки с помощью пост-обхода DFS.

**Сравнение с реальным менеджером пакетов (apt):**
В реальном менеджере пакетов `apt` порядок установки независимых пакетов 
может отличаться, так как `apt` использует свои эвристики (приоритеты, 
размер пакета). Кроме того, `apt` по умолчанию устанавливает `Recommends` 
и `Pre-Depends`, которые мы не парсим (в задании требуется только `Depends`).
При наличии циклов (как в тестовом `cycle.txt`) строгий топологический 
порядок невозможен, поэтому `apt` разрывает циклы по своим правилам, 
а наш DFS — по своим.
